# Implementing a Feature

Before writing code:

1. Read `CLAUDE.md`.
2. Read the relevant documents under `.ai/`.
3. Explain your implementation plan before writing code.
4. Keep the solution appropriate for a 3–6 hour take-home challenge.

Requirements:

- Angular 17 standalone components only.
- Use Signals for synchronous state.
- Prefer computed() over duplicated state.
- Use inject().
- Use OnPush.
- Avoid unnecessary abstractions.
- Keep business logic in pure functions.
- Do not use `any`.
- Add or update Jest tests.
- Explain important architectural decisions.

After implementation:

- Check formatting.
- Check lint.
- Check types.
- Check tests.
- Check production build.
